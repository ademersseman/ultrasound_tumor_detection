# ultrasound_tumor_detection
## Explanation
This repo contains code for training and testing a pytorch model that detects tumor regions from ultrasound imaging data. This is also my final project for Cornell's ORIE5270 course.

## Installation
```
pip install kagglehub torch opencv-python numpy matplotlib
python3 main.py
```

## Dataset
link: https://scholar.cu.edu.eg/?q=afahmy/pages/dataset
